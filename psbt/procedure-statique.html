Procédure pour site avec comptage BT

Coupure générale sur une installation BT, site avec un comptage BT. Les opérations électriques doivent être réalisées par un agent habilité BS ou BE minimum.

1. Panne d'électricité détectée

Constater l'absence d'alimentation sur le site et confirmer qu'il s'agit d'une coupure générale.

2. Vérification depuis le site ENEDIS

Consulter le site panne et interruption ENEDIS ou appeler le dépannage ENEDIS :

🔗 Ouvrir le site ENEDIS📞 09 72 67 50 64

  • Si une panne secteur est signalée : attendre le retour ENEDIS.
  • Sinon : déplacer un agent habilité BS ou BE minimum pour vérifier le comptage ENEDIS.

3. Vérification du comptage ENEDIS

  • Si le compteur Linky est en dépassement : ouvrir l'interrupteur général de l'armoire, arrêter tout le système de pompage, puis pour le tarif bleu appuyer sur le bouton + pour réarmer le Linky.
  • Si le disjoncteur ENEDIS n'est pas sur ON : ouvrir l'interrupteur général de l'armoire, arrêter le pompage, puis remettre le disjoncteur sur ON.
  • Si le Linky n'est pas en dépassement et que le disjoncteur ENEDIS est sur ON : vérifier le retour du courant.

4. Remise sous tension progressive

Refermer l'interrupteur général puis remettre les pompes une par une pour vérifier si le problème de disjonction ou de surcharge vient de l'une d'elles.

  • Si le défaut réapparaît : intervention maintenance.
  • Sinon : retour à l'exploitation normale avec surveillance renforcée.

5. Intervention maintenance

Faire intervenir le service maintenance pour diagnostic, réparation et remise sous tension si possible.

Contacts maintenance : 📞 06 29 19 45 22📞 06 20 00 30 98📞 06 20 57 60 14📞 06 22 72 73 50

6. Alerter le responsable process

En cas d'impossibilité de remise sous tension ou de défaut persistant, prévenir le responsable process.
